# Studio 1028

Dark-mode studio site for experiments, development, content creation, article writing, and social media marketing.

## Stack

- React 19 + TypeScript
- Vite
- Framer Motion
- Lenis smooth scroll
- Ready for Netlify (`netlify.toml` SPA redirect)
## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
